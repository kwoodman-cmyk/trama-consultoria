# TRAMA Consultora · sitio web

Sitio estático de tramaconsultora.com (HTML + CSS en línea, sin compilación).

- `index.html`: la página completa del sitio corporativo (servicios, productos propios, proyectos, cómo trabajamos, nosotros, liderazgo y contacto).
- `assets/`: logos de las organizaciones, capturas de los paneles y fuentes.
- `assets/fonts/`: Inter y Source Serif 4, alojadas en local. Ambas con licencia SIL Open Font License 1.1 (textos en `OFL-Inter.txt` y `OFL-Source-Serif-4.txt`).

## Publicación

Proyecto de Vercel `trama-consultora`. Con el repositorio conectado, cada fusión a `main` publica.
