# TRAMA Atiende · sitio web

Sitio estático de tramaconsultora.com (HTML + CSS en línea, sin compilación).

- `index.html`: la página completa.
- `assets/`: fotos, logos de clientes, capturas de los paneles y el video de portada.

## Publicación

Proyecto de Vercel `trama-consultora`. Con el repositorio conectado, cada fusión a `main` publica.
Sin conexión a Git, se puede arrastrar esta carpeta a la página del proyecto en Vercel.
